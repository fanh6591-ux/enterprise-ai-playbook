# 医疗科研资料治理与随访｜场景拆解

## 公开项目背景

Isaac 的[东方肝胆医院公开项目说明](https://isaac2024.online/work/details/hospital/)记录了相关科室科研资料整理、数据治理与随访方案，以及 AI 顾问的参与角色。材料描述的工作流包括资料识别、字段标准化、规则校验、医生复核和来源追溯。

原始资料来自病历图片、检验单、超声、病理及 Excel，跨时间和跨医院整理时，需要保留各项信息的出处与时间口径。

## 工作流的关键连接

| 环节 | 需要交付的结果 |
| --- | --- |
| 资料接收 | 原始资料引用、上传时间和记录归属 |
| AI 预处理 | 识别结果、字段候选值与原始出处 |
| 字段标准化 | 统一格式、单位、时间与缺失值口径 |
| 规则校验 | 字段冲突、缺失和异常标记 |
| 医生复核 | 专业人员确认后的记录与修改说明 |
| 查询与随访 | 可查询的数据，以及后续资料更新路径 |

## 为后续项目设计验证

这些是可用于试点的验证建议，由项目团队结合实际范围确定：

1. 为每个字段定义名称、格式、单位与原始来源，使用[数据字典](../templates/data-dictionary.csv)。
2. 选择同一批资料，记录人工方式与候选工作流的完整耗时。
3. 由专业人员按字段复核，分别记录识别错误、标准化错误、缺失和来源引用问题。
4. 把复核与返工时间纳入[实验记录](../templates/experiment-log.csv)。
5. 依据[验收计划](../templates/acceptance-plan.md)确认本次试点的质量与流程结果。

**材料状态**：公开项目页呈现现有方案；具体部署范围、验收状态和实测成效仍需项目资料补充。本篇用于科研资料整理的方法讨论，专业判断由相应人员复核。
